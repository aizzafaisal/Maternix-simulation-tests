# MaterNix virtual test dashboard

Simulated verification-by-analysis tests for the MaterNix GBS PCR cartridge (CT1–CT6) and smartphone optical read-out (OT tests). All results are simulated.

- `app.py` – Streamlit dashboard
- `cartridge_model.py`, `spectral_model.py`, `pipeline_sim.py` – models
- Run locally: `pip install -r requirements.txt` then `streamlit run app.py`

Code developed with AI assistance (Claude, Anthropic); tests designed and run by Aizza Faisal.
